# assets folder

Place these eight image files in this folder, using these exact filenames
(all lowercase, no spaces). The HTML already references these names.

| Filename                          | What it is                                       |
|------------------------------------|---------------------------------------------------|
| profile-picture.jpg                | Your headshot / LinkedIn profile photo             |
| generousplate.jpg                  | Screenshot of the GenerousPlate homepage           |
| owoahene-motors-logo.jpg           | Owoahene Motors logo design                        |
| artbyafricans.jpg                  | Screenshot of the ArtByAfricans homepage           |
| mobotech-auto-site.jpg             | Screenshot of the MoboTech Auto site               |
| kk-brothers-auto-site.jpg          | Screenshot of the KK Brothers booking site         |
| eggs-oil-hub-flyer.jpg             | Eggs & Oil Hub flyer design                        |
| operations-dashboard.png           | Screenshot of the operations dashboard             |

For the four live sites (GenerousPlate, ArtByAfricans, MoboTech, KK Brothers),
a clean full-page screenshot works well. On Chrome desktop: open DevTools (F12),
toggle device toolbar, then use the three-dot menu to "Capture full size screenshot".

Recommended before uploading:
- Resize the profile photo to roughly 800px wide.
- Resize project screenshots to roughly 1200px wide.
- Compress everything through squoosh.app or tinypng.com first.

Note: the Birthday Wish Generator project was dropped from the site in favor
of GenerousPlate and ArtByAfricans, so birthdaymessage.jpg is no longer needed.
